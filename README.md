# Zien 3D — 3D Architectural Visualisation Studio

Premium dark single-page website for Zien 3D by Zien Organisation.

## Structure
- `index.html` — Single-page site with all 8 sections
- `style.css` — Dark premium theme, mobile-first responsive
- `script.js` — Smooth scroll, lightbox, reveal animations, form handling
- `assets/` — Replace placeholder videos/images here

## Replacing Placeholders
1. **Hero video**: Add `assets/hero-reel.mp4` and `assets/hero-poster.jpg`
2. **Work cards**: Replace Unsplash URLs with your renders
3. **Work videos**: Add `assets/work-01.mp4` through `assets/work-06.mp4`
4. **About photo**: Replace the placeholder circle with an `<img>`
5. **OG image**: Add `assets/og-image.jpg` (1200×630px)
